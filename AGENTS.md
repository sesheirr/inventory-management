# Project Rules & Frontend Design Standards

This project has **Taste Skill** (`design-taste-frontend`, `redesign-existing-projects`, `high-end-visual-design`, `minimalist-ui`) activated.

## Frontend & UI Design Principles (Taste Skill)

When working on UI, Blade views, CSS, or frontend components in this project:
1. **Brief Inference & Aesthetic Polish**:
   - Read context and design language before writing frontend code.
   - Avoid generic AI templates (e.g., plain purple gradients, Inter + slate-900 default slop, centered generic cards).
   - Use curated harmonious color palettes, intentional typography, clean visual hierarchy, and balanced whitespace.
2. **Intentional Layout & Structure**:
   - Apply structured typography scale, consistent spacing rhythm (4px/8px scale), and accessible high-contrast colors.
   - For dashboards and management interfaces, prioritize high-legibility data density, clean tables/cards, responsive navigation, and intuitive interactive states.
3. **Micro-Interactions & Transitions**:
   - Add purposeful hover, focus, and transition effects (`cubic-bezier(0.16, 1, 0.3, 1)` or standard smooth curves).
   - Include proper focus-visible rings and active feedback for buttons and form controls.
4. **Full Completeness**:
   - Deliver complete, unabridged, production-ready views and styling without omitting code or leaving placeholders.
